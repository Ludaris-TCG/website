# Reglas

- Las páginas no deben superar 100 líneas.
- Los componentes no deben superar 200 líneas.
- Los componentes resuelven una única responsabilidad.
- Nunca repetir Tailwind cuando exista un componente UI.
- Toda navegación vive en `lib/navigation.ts`.
- Todos los imports usan `@/`.
- Todo dato de dominio tiene su tipo en `types/`.
